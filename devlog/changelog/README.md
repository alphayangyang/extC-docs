## 写法

- 新条目写进**当月那一页的顶部**：`## YYYY-MM-DD · 标题`，正文跟着它。
- 月份翻页时新建同目录的 `YYYY-MM.md`，再跑一次 `tools/check_changelog.py --write` —— `--gate` 会对着月份页核对条目数与日期范围。
- 本页不写正文；"最近改了什么"直接读当月那一页。这里只在翻月时动一次。
